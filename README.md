### 本專案為 114 學年度第一學期《微算機概論》期末專題，基於 **Raspberry Pi Pico 2W** 微控制器實作的嵌入式遊戲機系統 ###

## 專案概述
本系統以「單一硬體平台、多元遊戲內容」為設計理念，透過模組化軟體架構，在有限的硬體資源下實現了多款經典遊戲。系統整合了輸入控制、顯示處理與音效輸出，驗證了 Pico 2W 在嵌入式系統應用上的可行性。

## 功能特色
- **多元遊戲體驗**：內建多款遊戲，包含：
  - **Tetris (俄羅斯方塊)**：經典方塊堆疊與消除邏輯。
  - **Space Shooter (太空射擊)**：即時操作與碰撞判斷。
  - **Maze Game (迷宮)**：路徑探索挑戰。
  - **Guess Number (猜數字)**：人機互動邏輯判斷。
  - **Table Tennis (桌球)**：模擬對戰模式。
- **模組化架構**：
  - `InputUnit`：負責類比搖桿與按鈕輸入處理。
  - `DisplayUnit`：基於 SSD1306 的 OLED 螢幕顯示控制。
  - `MenuSystem`：基於 JSON 格式的選單管理系統。

## 硬體架構
- **核心處理單元**：Raspberry Pi Pico 2W
- **輸入裝置**：雙軸類比搖桿 (VRx, VRy) 及搖桿按鈕 (SW)
- **輸出裝置**：SSD1306 OLED 顯示螢幕、被動蜂鳴器 (Buzzer)
- **通訊介面**：SPI 通訊協定 (高速刷新 OLED)、ADC (類比訊號讀取)

## 系統流程
系統啟動後，依序執行：
1. 讀取 `menu.json` 選單設定檔。
2. 初始化輸入與顯示模組。
3. 建立 MenuSystem 選單結構。
4. 進入主迴圈監聽使用者操作。
